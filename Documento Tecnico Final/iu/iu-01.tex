\section{IU-01 Dashboard principal de noticias}

\subsection{Objetivo}
	Permitir al analista monitorear el corpus de noticias clasificadas asi como realizar búsquedas de
	texto completo y acceder a las funcionalidades de investigación profunda y seguimiento de casos.

\subsection{Diseño}
	Esta pantalla es la vista inicial del sistema tras autenticarse. En la cabecera superior se
	presenta una fila de tarjetas de métricas (widgets) que dicen el total de noticias, noticias con
	NNA identificados, noticias de Alta relevancia, Media relevancia y número de tópicos BERTopic
	generados asi como un  selector de clasificación (Alta / Media / Baja / Todas) que filtran el
	contenido de forma sincronizada.
	Debajo un \textbf{panel de lista} con tarjetas interactivas
	paginadas de noticias. Cada tarjeta incluye: título, fuente, fecha, score semántico BETO,
	etiquetas de clasificación codificadas por color (rojo: Alta, naranja: Media, gris: Baja).
	La barra superior contiene una barra de búsqueda de texto completo (FTS).

\IUfig[.9]{dashboard_principal}{IU-01}{Dashboard principal de noticias.}

\subsection{Salidas}
	\begin{itemize}
		\item Tarjetas de métricas: total noticias, noticias NNA, Alta, Media, número de tópicos.
		\item Lista paginada de noticias con título, fuente, fecha y score BETO.
		\item Notificaciones de estado del análisis de noticias (en ejecución, completado o error).
	\end{itemize}

\subsection{Entradas}
	\begin{itemize}
		\item Término de búsqueda FTS (barra de búsqueda, referencia a CU-07).
		\item URL externa para investigación profunda (formulario, referencia a CU-04).
		\item Selector de clasificación (Alta / Media / Baja / Todas).
		\item Selector de lote de análisis (último, todos o específico).
		\item Filtro ``Solo NNA'' (interruptor booleano).
	\end{itemize}

\subsection{Comandos}
	\begin{itemize}
		\item \IUbutton{Actualizar datos}: Dispara el flujo de recolección y
		      clasificación en segundo plano (CU-01).
		\item \IUbutton{Casos objetivo}: Manda a el módulo \texttt{DeepInvestigator} sobre la noticia
		      seleccionada y ejecuta la investigación profunda (CU-03).
		\item \IUbutton{Identificar caso}: Procesa la URL introducida manualmente (CU-04).
		\item \IUbutton{Exportar CSV}: Descarga el corpus completo clasificado (RF-10).
		\item \IUbutton{Limpiar Historial}: Borra todos los registros de la base de datos,
		      los CSVs y la caché de URLs procesadas (RF-14).
	\end{itemize}
