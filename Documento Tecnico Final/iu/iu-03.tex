\section{IU-03 Módulo de investigación profunda}

\subsection{Objetivo}
	Muestra la síntesis estructurada generada por el agente de Inteligencia Artificial (Gemini Flash) sobre un caso crítico de orfandad.

\subsection{Diseño}
	Esta interfaz se presenta como dentro de la pestaña de casos objetivo del Dashboard.
	Muestra la información estructurada en tarjetas (Ubicación, Víctimas, contacto a instituciones que pudiesen proporcionar mas información, etc.). Durante el proceso, muestra un indicador de carga.

\IUfig[.8]{investigacion_modal}{IU-03}{Modal de Resultados del DeepInvestigator.}

\subsection{Salidas}
	\begin{itemize}
		\item Título y resumen generados por el modelo de lenguaje.
		\item Datos estructurados: Ubicación geográfica del suceso, edades y géneros de las víctimas, NNA afectados.
		\item URL de referencia y dependencias sugeridas (por ejemplo, DIF Municipal).
		\item Alerta de error si ocurre un fallo en la API (por ejemplo, cuota excedida o fallo de DDG).
	\end{itemize}
	
\subsection{Entradas}
	\begin{itemize}
		\item Ninguna (es una interfaz de lectura resultante del CU-03).
	\end{itemize}

\subsection{Comandos}
	\begin{itemize}
		\item \IUbutton{Investigar mas en la web}: Ejecuta el flujo de investigación profunda (CU-03).
		\item \IUbutton{Agregar a Seguimiento}: Etiqueta el caso como relevante e inserta la noticia investigada en la lista de monitoreo activo (CU-05).
	\end{itemize}
